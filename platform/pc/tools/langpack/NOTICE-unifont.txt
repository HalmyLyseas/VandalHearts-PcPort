unifont-subset.bdf
==================

This file is a SUBSET of GNU Unifont (version 17.0.03), trimmed to the codepoint ranges the language
tooling generates glyph art for -- Latin-1 Supplement + Latin Extended (U+00A0..U+024F), Greek and
Coptic (U+0370..U+03FF), and Cyrillic (U+0400..U+04FF), 832 glyphs. It is used by gen_packart.py as
the raw bitmap source when generating a non-Latin pack's glyph sheets. Every glyph is Unifont's own
unmodified pixels; only the character set was reduced.

To regenerate this subset from a full unifont.bdf, keep the BDF header and only the STARTCHAR blocks
whose ENCODING falls in the ranges above (updating the CHARS count).
